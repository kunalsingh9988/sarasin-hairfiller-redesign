# Hairfiller homepage — export-led adaptation

The supplied `Homepage.pdf` (1600 px wide) and `Frame 1484581785.pdf` (360 px wide) define the composition. This is not an exact replica of another brand: the user explicitly requires Sarasin content, colours and typography.

## Visual contract

- Split desktop hero with result-led visual; image-first mobile hero. Original clinic comparisons replace the reference's staged head progression.
- Preserve the original page's exact heading and content-item sequence, including numbered sections 1–6. The supplied reference informs styling, never a different reading order.
- Source content belongs in its corresponding section. The complete peptide table stays visible between its original introduction and explanation. Only the long photo gallery, original animation and FAQ answers use native disclosures; no separate archive substitutes for main content.
- Bricolage Grotesque throughout, self-hosted 400/500/600/700, including the wordmark, headings, tables and controls on every supporting page.
- Ink `#153f3b`, secondary `#4b6761`, sage `#e5efea`, cream `#f8f7f2`, citrine CTA `#dce784`, rules `#cadbd3`, white paper. CTA colour remains subject to client approval.
- Desktop side gutters 48px; mobile 24px (18px at 370px or narrower). Fluid two-column layouts become single-column reading paths at 700px.
- Section spacing 88px desktop / 48px mobile; 16px photo/card corners; 12px buttons. Body 17px desktop / 16px mobile.
- Lucide icons from the existing local icon library. No emoji/glyph substitutes for navigation actions.

## Behaviour and honesty

The hero changes every two seconds, offers manual selection and pause, stops when the document is hidden, and defaults to paused with reduced motion. Mobile navigation overlays rather than displaces content. Videos load only after a click and are removed when the dialog closes. Mobile reading order matches the source and desktop DOM, without CSS reordering the original content.

Original clinical imagery is not altered. Added lifestyle imagery is labelled as illustrative/AI-generated, not a result or proof. No RegrowthClub names, invented ratings, unverified review totals, subscription prices or guarantees are transferred from the reference.
